# Where next

This is the last lesson of the main tour. A case study follows it: [lesson 34](../34-morphir-ir-types/lesson.md) and the next five lessons model the Morphir IR in Smithy. Each link below opens a page that goes further.

- [The Smithy specification](https://smithy.io/2.0/spec/index.html) defines the shapes, the traits and the rules of the language.
- [The playground](../../../playground/README.md) runs Smithy in the browser on a model of your own.
- [The `smithy` CLI](../../../../apps/smithy/README.md) shows each command and its options.
- [The library moonrockz/smithy](../../../../pkgs/smithy/README.mbt.md) loads and assembles IDL and JSON AST models in MoonBit.
- [Value validation](../../../../pkgs/smithy-validation/README.mbt.md) checks application values against the shapes of a model.
- [JSON-RPC validation](../../../../pkgs/smithy-validation/rpc/README.mbt.md) checks JSON-RPC messages against a Smithy service.
- [Parse a model](../../../../docs/cookbook/parsing.mbt.md) reads IDL text into the AST, the CST and the diagnostics.
- [Traverse a model](../../../../docs/cookbook/traversal.mbt.md) gives one node model over the AST, with names from the Smithy JSON AST.
- [Report problems](../../../../docs/cookbook/diagnostics.mbt.md) renders the diagnostics for a terminal, for a log or for an editor.
